WORKING WITH LOCAL STORAGE

1. We use local storage API in order to make workout data persist across multiple page reloads.
2. Local storage is place in the browser where we can store the data that will stay there even after we close the page . So ,basically the data is linked to the URL on which we are using the application.
3. Workout gets stored in local storage whenever the user creates a new workout → in _newWorkout().
4. Create a new method called _setLocalStorage() and call it in _newWorkout();
5. This method does not need parameters because we simply will get the workouts from the workout property.
6. Local storage API is a simply key value store.

```jsx
localStorage.setItem(’workouts’,JSON.stringify(this.#workouts))
```

local storage takes strings as key and value.

JSON.stringify() → convert any object in JS to a string.

JSON.parse() → convert string to object.

1. The data in local storage could be seen → go to inspect → application → storage → local Storage → url. There you can see key is workouts and value is the data . Local storage is always gonna be up to dated.
